# L4D2 黑枪统计（Friendly-Fire Stats）

一个不依赖 SourceMod 的《求生之路 2》VScript 模组，用于统计本地服务器中幸存者之间的队友伤害（俗称“黑枪”），并定时在聊天栏公示。

## 功能特性

- 通过 VScript 监听 `player_hurt` 事件，仅统计攻击者和受害者**都属于幸存者队伍**的伤害。
- 分别记录每位玩家造成的伤害总值和次数；自伤、感染者伤害、环境伤害不会计入。
- 默认每 60 秒向全体玩家的聊天栏发送当前地图累计总计和逐玩家明细。
- 报告后不会清零，统计会跨回合持续累计；只有**更换地图时自动清空**。
- 模组不会修改游戏的友伤倍率或伤害规则，只读取游戏已经产生的伤害事件。

## 文件说明

本模组采用“加载器 + 核心逻辑”结构，包含两个文件：

| 文件名 | 作用 |
| --- | --- |
| `director_base_addon.nut` | 入口加载器，负责调用核心逻辑 |
| `ffstats_core.nut` | 核心统计逻辑 |

## 安装方法（推荐：本地脚本方式）

这种方式最简单，且**优先级最高**，不会被其他 VPK 模组覆盖。

1. 找到游戏目录下的以下路径（如果没有 `vscripts` 文件夹，请手动新建）：

    ...\Left 4 Dead 2\left4dead2\scripts\vscripts\

   例如：

    D:\Steam\steamapps\common\Left 4 Dead 2\left4dead2\scripts\vscripts\

2. 将 `director_base_addon.nut` 和 `ffstats_core.nut` 两个文件**直接复制**到上述 `vscripts` 文件夹中。

3. 启动游戏，正常创建本地服务器（战役模式，选择“本地服务器”）。进入地图后，模组会自动加载。

> **提示**：不需要打包成 VPK，也不需要经过创意工坊。直接放本地文件即可生效。

## 使用方法

- 当你是房主并开启本地服务器后，脚本会自动运行。
- 每 60 秒，聊天栏会显示类似信息：

    [黑枪统计] 本地图累计队友伤害：XX 点，共 X 次。
      玩家A：XX 点伤害，X 次
      玩家B：XX 点伤害，X 次

- 若本图尚未发生队友伤害，则显示：

    [黑枪统计] 本地图尚未检测到队友伤害。

- 换图（推进章节）后，统计自动清零并重新累计。

## 联机说明

- 本模组是**服务端脚本**，只要**房主**安装并生效，房间内所有玩家都能在聊天栏看到统计。
- 其他玩家不需要安装任何文件。
- 如果朋友也想自己开房使用，只需把这两个 `.nut` 文件复制到他们的 `left4dead2\scripts\vscripts\` 目录即可。

## 兼容性与冲突处理

本模组包含 `director_base_addon.nut` 这个入口文件。在 L4D2 中，许多 VScript 模组都会争抢这个入口，导致**只有优先级最高的那个能运行**。如果你同时使用了其他 VScript 模组，可能会发生冲突。

### 如何判断是否冲突？

- 如果进入游戏后，聊天栏没有出现黑枪统计，或者控制台（按 `~` 打开）没有打印 `[FFStats] Loader initialized, loading core...`，则可能是入口被其他模组覆盖了。

### 解决方案：手动合并加载器

1. 找到那个与你冲突的模组的 `director_base_addon.nut` 文件（通常在它的 VPK 内，或用本地文件方式找到）。
2. 用文本编辑器打开它，在文件末尾添加一行：

    IncludeScript("ffstats_core");

3. 保存并重新打包（如果是 VPK），或者直接放回本地 `vscripts` 目录。
4. 这样两个模组就能共存了。

> **推荐做法**：将本模组的两个 `.nut` 文件放在本地 `left4dead2\scripts\vscripts\` 目录中，因为本地文件的优先级高于任何 VPK。这样你的黑枪统计就不会被创意工坊的 VPK 覆盖。

## 常见问题

**Q：为什么我安装后没有反应？**  
A：请检查文件是否放对了路径，并且文件名是否正确。可以在控制台输入 `script_execute director_base_addon` 手动加载（需先 `sv_cheats 1`），观察是否有报错。

**Q：换图后统计会保留吗？**  
A：不会，换图时会自动清零。这是设计如此。

**Q：可以统计 AI 队友的伤害吗？**  
A：本模组只统计玩家控制的幸存者之间的伤害。AI 队友不会对队友造成伤害，因此不影响。

**Q：会影响游戏平衡吗？**  
A：不会。它只是读取事件并显示统计，不修改任何游戏规则。

## 卸载方法

- 直接删除 `left4dead2\scripts\vscripts\` 目录下的 `director_base_addon.nut` 和 `ffstats_core.nut` 即可。
- 如果使用了 VPK 打包，则删除对应 VPK 文件。
